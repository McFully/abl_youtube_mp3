# Stack Tecnológico - ABL Youtube

## Frontend & Renderer Process
- **React v19.2.5**: Librería de interfaz basada en componentes funcionales y Hooks (`useState`, `useEffect`).
- **Framer Motion v12.38.0**: Motor de animaciones de interfaz para transiciones fluidas y colas animadas (`AnimatePresence`, `motion.div`).
- **Lucide React v1.14.0**: Colección de iconos vectoriales optimizados (`Download`, `FolderOpen`, `X`, `Minus`, `Square`, `Music`, `Compass`, `AlertTriangle`).
- **Vanilla CSS (Variables CSS Custom)**: Sistema de diseño atómico glassmorphic con gradientes radiales y desenfoque `backdrop-filter`.

## Runtime & Desktop Framework
- **Electron v41.5.0**: Framework ejecutable multiplataforma Node.js + Chromium.
- **Vite v8.0.10**: Bundler ultra rápido con plugins `vite-plugin-electron` y `vite-plugin-electron-renderer`.
- **Electron Builder v26.8.1**: Empaquetador nativo para Windows (.exe / portable / nsis).

## Herramientas de Procesamiento de Medios
- **yt-dlp.exe**: Extractor de vídeo y listas de reproducción de código abierto.
- **ffmpeg.exe**: Conversor multimedia nativo para extracción de stream de audio Opus/AAC a MP3 CBR/VBR alta fidelidad.
