# Glosario de Términos - ABL Youtube

- **yt-dlp**: Bifurcación popular de `youtube-dl` optimizada con mejoras de velocidad y soporte activo para la extracción de vídeo/audio.
- **FFmpeg**: Framework multimedia capaz de decodificar, codificar, transcodificar y filtrar cualquier formato de audio o vídeo.
- **Frameless Window**: Ventana gráfica de Electron sin bordes ni barra de título predeterminada del sistema operativo.
- **IPC (Inter-Process Communication)**: Mecanismo de comunicación entre el proceso Principal (Node.js) y el proceso de Renderizado (Chromium/React) de Electron.
